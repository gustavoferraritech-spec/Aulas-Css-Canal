# Estudos de CSS 🎨

Este repositório foi criado para guardar os códigos e atividades de **CSS** desenvolvidos durante as aulas.

A ideia é deixar todos os exercícios organizados em um só lugar, mostrando minha evolução e os diferentes recursos de CSS que foram trabalhados durante as aulas.

## 📚 Conteúdo

Durante as atividades, serão trabalhados diferentes conceitos de CSS, como:

* Seletores
* Cores
* Fontes e textos
* Margens e espaçamentos
* Bordas
* Backgrounds
* Box Model
* Classes e IDs
* Pseudo-classes
* Flexbox
* Grid
* Posicionamento
* Responsividade
* Animações
* Transições
* Efeitos visuais
* Organização e estilização de páginas

## 📁 Organização

Os códigos serão separados conforme as atividades realizadas em aula.

```text
📦 estudos-css
 ┣ 📁 aula-01
 ┣ 📁 aula-02
 ┣ 📁 aula-03
 ┣ 📁 aula-04
 ┣ 📁 exercicios
 ┗ 📄 README.md
```

A organização pode mudar conforme novos exercícios forem adicionados.

## 🖥️ Como visualizar

Como os códigos são voltados para CSS, alguns exercícios podem precisar de um arquivo HTML para serem visualizados corretamente.

Para testar os projetos:

1. Baixe ou clone este repositório.
2. Abra a pasta da atividade que deseja visualizar.
3. Abra o arquivo `.html` no navegador.
4. Observe as alterações feitas pelo CSS.

Também é possível utilizar o **Visual Studio Code** para editar e testar os arquivos.

## 🎯 Objetivo

O objetivo deste repositório é acompanhar as atividades realizadas durante as aulas e praticar os conceitos de CSS na criação e estilização de páginas.

Os códigos aqui presentes fazem parte do meu processo de aprendizado e podem ser modificados conforme novos conteúdos forem aprendidos.
